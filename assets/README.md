# assets/

Contains all static assets used in the project.

## Folders

- **images/** - Store all images, icons, and illustrations exported from the Figma design here.

## Guidelines

- Export images from Figma in the appropriate format (SVG for icons, PNG/WebP for photos).
- Use descriptive file names (e.g., `hero-illustration.svg`, `logo-white.png`).
- Optimize images for web before adding them to keep the repo lightweight.
